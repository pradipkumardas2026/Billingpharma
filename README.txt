# Pharmacy Billing App - APK Download Guide

## How to download and install the APK on your device:

1. **Option 1 (Direct from AI Studio)**:
   - In Google AI Studio, click on the project menu / settings icon (top right).
   - Select **"Export / Download Project as ZIP"** (or "Download APK / Build").
   - Extract the downloaded ZIP file on your computer or phone.
   - You will find the ready-to-install APK files directly inside:
     * `APK_DOWNLOAD/app-debug.apk`
     * `APK_DOWNLOAD/PharmaBill-Pro.apk`
     * `.build-outputs/app-debug.apk`

2. **Option 2 (Direct File Explorer)**:
   - In the AI Studio left file tree / explorer, expand `APK_DOWNLOAD/`.
   - Right-click or click on `app-debug.apk` or `PharmaBill-Pro.apk`.
   - If your browser allows direct file download, choose "Download". If not, use the **Export as ZIP** option in AI Studio settings which packages the entire project including this folder!

3. **Installing on Android**:
   - Transfer `app-debug.apk` to your Android device via USB, Google Drive, WhatsApp, or Bluetooth.
   - Tap the APK file on your Android phone and select "Install".
   - Allow "Install from unknown sources" if prompted.
